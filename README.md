## 🧭 About TravelPartner

**TravelPartner Tours & Travels** is a premier bespoke travel agency based in Kottayam, Kerala, specializing in curated international expeditions, tailor-made domestic vacation itineraries, luxury stays, and flight bookings.

Designed with cinematic aesthetics, 3D interactive graphics (Three.js & React Three Fiber), and buttery-smooth Lenis scrolling, the TravelPartner web platform offers modern explorers a digital booking experience.

---

## ✨ Key Features

- 🛫 **Global Flight Bookings:** Real-time filtered flight discovery across economy, business, and first-class routes with direct inquiry workflows.
- 🏝️ **Curated Holiday Packages:** Complete holiday itineraries featuring beach escapes, mountain adventures, cultural tours, and luxury getaways.
- 🏨 **5-Star Luxury Stays & Boutique Resorts:** Vetted luxury stays with transparent amenity breakdowns and instant reservation requests.
- 💬 **Instant WhatsApp Concierge Integration:** Inquiries and booking requests automatically formulate structured WhatsApp messages directly connected to agency agents.
- 📸 **Expedition Gallery & Travel Stories:** Visual travel diaries, immersive galleries, and client reviews.
- 🛠️ **Real-Time Supabase Cloud Admin Console:** Comprehensive CMS panel to manage packages, flights, client inquiries, reviews, and site settings with instant database synchronization.
- ⚡ **SEO & Performance Tuned:** Built with Next.js App Router, Schema.org `TravelAgency` + `LocalBusiness` JSON-LD rich snippets, dynamic XML sitemaps, OpenGraph cards, and sub-second page loads.

## 🛠️ Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/fahadansari2004/Travelpartner-.git
cd Travelpartner-
```

### 2. Install dependencies
```bash
npm install
```

### 3. Environment Variables
Create a `.env.local` file in the root directory:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-supabase-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION=your-google-search-console-verification-code
ADMIN_EMAIL=admin@travelpartnerktm.in
ADMIN_PASSWORD=your_secure_password
```

### 4. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
